# Quickstart — test guidé du lot A

## Prérequis
`npm run seed:demo` (profil démo, pont déjà enregistré) ; Claude Code connecté.

1. **Toile** : clic droit dans le vide › Idée › « Ouvrir un studio photo ».
2. **Double-clic** sur l'idée → le panneau de chat s'ouvre ; Claude pose une première question liée au titre.
3. **Trois échanges** : réponds librement. **Attendu** : texte en flux ; pastilles « fiche mise à jour » ; la fiche
   (panneau) contient tes décisions ; le neurone grossit et affiche son résumé sur la carte.
4. **Arrêter** pendant une réponse → le tour s'arrête ; la fiche déjà écrite reste.
5. **Historique** : ferme le panneau, redémarre l'app, rouvre → l'historique est là ; demande « où en est-on ? » → Claude
   s'appuie sur ce qui a été dit.
6. **Annuler** : Historique › « Claude : fiche » → annuler → la fiche revient à l'état d'avant.
7. **Limites** : demande à Claude de lancer une commande ou d'écrire un fichier → il ne peut pas (refusé d'office).
