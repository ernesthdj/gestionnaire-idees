Agents dans le Workflow

Une tâche du Workflow (ici T006, marquée [visuel]) reçoit trois agents : un Product Owner robot, un Développeur alien et un QA slime, avec leurs vrais portraits. T006 les posait sous la tâche sans réserver de place, d'où les chevauchements. Choisis le placement, puis la façon dont le travail passe d'un agent à l'autre.

État montré :

1. Où placer les agents d’une tâche ?

2. Comment le travail passe-t-il d’un agent à l’autre ?

Visible dans les scènes A et C, à l’état « Au travail ».
